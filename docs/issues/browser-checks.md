## 목적 또는 문제

자동 회귀 검증은 Node VM과 Sharp 기반이다. 실제 브라우저별 다운로드·클립보드·Canvas 동작은 별도 기록이 필요하다.

## 완료 조건

- [ ] 검증이 허용된 환경에서 Chrome/Safari 버전과 OS를 기록한다.
- [ ] 불투명/투명 PNG의 3840 × 2160 크기와 알파를 확인한다.
- [ ] 온라인 타일 CORS·실패 재시도·저장 중 카메라 변경을 확인한다.
- [ ] 좌표 복사와 세션 초기화 동작을 확인한다.
- [ ] 브라우저 접근 제한을 우회하지 않고 결과를 이슈에 남긴다.

## 검증과 현재 상태

이 이슈는 브라우저 수동 점검의 미완료 상태를 추적한다. 자동 검증 통과와 구분한다.
